## Git - GitHub

Git ist eine freie und quelloffene Software zur Versionsverwaltung. Es wurde 2005 entwickelt und hat sich inzwischen als De-facto-Standard für die Versionsverwaltung in der Softwareentwicklung etabliert.

GitHub ist ein Onlinedienst, der auf Git basiert und die gemeinsame Arbeit an Projekten sowie die transparente Veröffentlichung und Weitergabe von Code ermöglicht. Darüber hinaus kann GitHub dazu genutzt werden, den aktuellen Stand lokaler Arbeiten zu sichern und Entwicklungsprozesse nachvollziehbar zu dokumentieren.

Eine weitere etablierte Anwendung in diesem Bereich ist GitLab. Die Universität erprobt diesen Dienst derzeit unter https://gitlab.rz.uni-frankfurt.de.

Neben der Versionsverwaltung und Zusammenarbeit mit Git und GitHub sind auch die Auffindbarkeit, Zugänglichkeit und Nachnutzbarkeit von Forschungssoftware wichtige Aspekte einer nachhaltigen Softwareentwicklung.

## FAIR-Prinzipien für Forschungssoftware

* findable: Software und die dazugehörigen Metadaten sind sowohl für Menschen als auch für Maschinen leicht auffindbar.
* accessible: Software und ihre Metadaten sind über standardisierte Protokolle abrufbar.
* interoperable: Software ist mit anderer Software interoperabel, indem sie Daten und/oder Metadaten austauscht und/oder über Anwendungsprogrammierschnittstellen (APIs) interagiert, die durch Standards beschrieben sind.
* reusable: Software ist sowohl nutzbar (kann ausgeführt werden) als auch wiederverwendbar (kann verstanden, modifiziert,
weiterentwickelt oder in andere Software integriert werden)

Die FAIR4RS-Prinzipien sind unter https://doi.org/10.15497/RDA00068

veröffentlicht und können zitiert werden. Sie bieten eine Orientierung für den Umgang mit Forschungssoftware, ähnlich wie die FAIR-Prinzipien für Forschungsdaten.

Für die Erstellung und Bearbeitung eines Software Management Plans (SMP), der sich eng an den FAIR4RS-Prinzipien orientiert, empfehlen wir unseren Service RDMO@GU. Dort kann ein SMP-Projekt angelegt werden, in dem gezielt Fragen gestellt werden, die auf die jeweiligen Anforderungen zugeschnitten sind. Wie ein Data Management Plan (DMP) für Forschungsdaten kann ein SMP außerdem bei der Planung und Durchführung von Forschungsprojekten sowie bei Anträgen auf Drittmittelförderung unterstützen.
